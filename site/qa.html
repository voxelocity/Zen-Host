Questions & answers

Everything you might
wonder about Zen Host

The short answers. If something is broken or throwing an error, the Support page has the technical fixes.

Basics

What exactly is Zen Host?

A desktop app that creates, runs and manages Minecraft Java Edition servers for you. It downloads the right server files, writes the config, launches the Java process and gives you a dashboard with a live console — so you never touch a command line or hand-edit server.properties.

It runs the server on your own machine. It isn't a paid hosting service, and nothing is uploaded to anyone else's computer.

Is it free? Is there a catch?

Free, and open source under the MIT licence. No account, no subscription, no telemetry. The full source is on GitHub.

Does it work with Bedrock Edition (phones, console, Windows 10/11 Store)?

No — Zen Host runs Java Edition servers only. Bedrock uses a completely different server program and network protocol, so Bedrock clients can't join a Java server without a third-party proxy such as GeyserMC (which Zen Host doesn't manage for you).

Which operating systems are supported?

Windows 10/11, macOS 11 Big Sur or newer, and glibc-based Linux distributions — each on both 64-bit Intel/AMD and ARM. Apple Silicon Macs and ARM Windows laptops get native builds, not emulated ones.

Every format is listed on the download section.

Do I need to install Java?

Yes. Zen Host bundles everything it needs to run itself, but the Minecraft server is a Java program, so a JDK has to be present. Install Java 21 — Minecraft 1.20.5 and newer require it, and it also runs older versions fine.

Zen Host looks for Java in JAVA_HOME, macOS's /usr/libexec/java_home, your PATH, and the standard install directories, so it usually finds an existing install with no setup.

How much does a server slow my computer down?

A Minecraft server is mostly single-threaded CPU work plus whatever RAM you assign it. A 2 GB vanilla server with a handful of players is light; a big modpack with 8 GB and a large view distance is not.

Assign at most half to two-thirds of your physical RAM, and remember the Minecraft client needs its own share if you're playing on the same machine.

Servers

Which server type should I pick?
  • Vanilla — the official Mojang server. Nothing added, nothing that can break. Pick this if you just want normal Minecraft.
  • Paper — a performance-tuned fork that also runs Bukkit/Spigot plugins. Best for a survival server with several players.
  • Fabric — a light, fast-updating mod loader. First to support new Minecraft versions.
  • Forge — the veteran loader behind most large modpacks.
  • NeoForge — the community-run successor to Forge for 1.20.2+, with a cleaner API.

Mods and plugins are not interchangeable: a Fabric mod won't load on Paper, and a Bukkit plugin won't load on Forge.

Can I change a server's type or version after creating it?

Not from the UI. The type determines the whole folder layout and how the server is launched, so switching would mean replacing the server files entirely.

Create a new server of the type you want, then copy your world folder across from the old one. World data itself is type-agnostic, though modded worlds will lose blocks and items from mods you don't carry over.

Which Minecraft versions can I run?

The version list is fetched live from each project's own API, so it's always current:

  • Vanilla — every release listed in Mojang's version manifest (snapshots are filtered out).
  • Paper — every version PaperMC currently builds for, newest first.
  • Fabric / Forge / NeoForge — whatever each loader publishes for that Minecraft version.
How much RAM should I give a server?

Rough starting points:

  • Vanilla or Paper, 1–5 players — 2 GB
  • Paper with plugins, 5–15 players — 4 GB
  • Small mod set (10–40 mods) — 4–6 GB
  • Large modpack (150+ mods) — 8 GB or more

More is not automatically better — a very large heap can make garbage-collection pauses worse. Raise it only if you actually see out-of-memory errors in the console.

What is the EULA prompt?

Mojang requires anyone running a Minecraft server to accept their End User Licence Agreement. The server refuses to boot until it sees eula=true in a file called eula.txt.

Accepting the prompt in Zen Host writes that file for you. It's a one-time thing per server.

Can I run more than one server at once?

Yes, as long as each one uses a different port and your machine has the RAM for all of them. Change server-port under Settings → Network before starting the second server, otherwise it will fail to bind.

What happens to my server when I close Zen Host?

Running servers are stopped cleanly when the app quits, so the world saves properly and no stray Java process is left behind.

On macOS, closing the window doesn't quit the app — the server keeps running and you can reopen the window from the Dock. Use Cmd + Q to actually quit and shut the server down.

Playing together

How do my friends join my server?

Three addresses, depending on where they are:

  • Same computer — localhost
  • Same Wi-Fi / network — the LAN address shown on the Overview tab, like 192.168.1.24:25565
  • Anywhere else — the public address, like bore.pub:41287

Each has a copy button on the Overview tab.

Do I have to port-forward my router?

No. When a server is marked public, Zen Host opens a tunnel to the free bore.pub relay and gives you an address that works from anywhere — no router settings, no firewall rules, no dynamic-DNS.

Port forwarding is still an option if you'd rather have a fixed address and slightly lower latency.

Is my public address the same every time?

No — the relay assigns a random port each time the server starts, so bore.pub:41287 might be bore.pub:38104 tomorrow. Re-copy it from the Overview tab and send the new one to your friends after each restart.

Port-forwarding your own router is the way to get a permanent address.

Is the public tunnel safe? Who can see my server?

The tunnel simply forwards traffic between the relay and your server — anyone who has the address can attempt to connect, exactly as with a port-forwarded server. It isn't listed or advertised anywhere, but it also isn't secret.

If you want to be certain only invited people get in, turn on the whitelist under Settings → Network and add your friends. You can also flip the server back to private at any time to close the tunnel.

Can players without a Minecraft account join?

Only if you turn Online Mode off under Settings → Network, which disables Mojang account verification.

Be aware of the trade-off: with online mode off, anyone can connect using any username, including yours. Player identity is no longer verified, so pair it with a whitelist if you use it at all.

How do I give myself (or a friend) admin powers?

Open the Operators tab, type the Minecraft username and add it. Zen Host looks the account's UUID up from Mojang and writes ops.json for you, so it works even while the server is stopped.

Operator levels run 1–4; level 4 is full access, including /stop. If the server is running, the op command is issued immediately so it takes effect without a restart.

How do I set up a whitelist?

Turn on Whitelist Enabled under Settings → Network, then add players from the console tab with whitelist add PlayerName. Turn on Enforce Whitelist as well to kick anyone already connected who isn't on the list.

Mods

How do I install mods?

Open the Mods tab and drag .jar files straight onto the window, or use the browse button. They're copied into the server's mods folder.

Restart the server for changes to take effect. The tab has a toggle to disable a mod without deleting it (it's renamed to .jar.disabled, which the loader ignores).

This applies to Fabric, Forge and NeoForge servers. Paper uses plugins instead, which live in a plugins folder.

Do my friends need the same mods installed?

For most mods, yes — anything that adds blocks, items or entities has to be on both the client and the server, at matching versions and on the same loader. Players without them will be rejected at login.

Some mods are server-side only (performance tweaks, world pre-generators, moderation tools) and need nothing on the client. Mod pages usually state which side they're required on.

Where do I get mods from?

Modrinth and CurseForge are the two standard sources. Always download the build matching your Minecraft version and loader, and take the server-side file where one is offered separately.

Does Fabric need Fabric API?

Most Fabric mods do. It's a separate mod jar that you install the same way as any other — download the build matching your Minecraft version and drop it in with the rest. A missing Fabric API is one of the most common reasons a Fabric server exits on startup.

What is the Far Render tab?

A one-click installer for the server-side half of extended-view-distance setups. It fetches builds matching your server's version and loader from Modrinth:

  • Distant Horizons — level-of-detail terrain far beyond normal view distance
  • Voxy — a similar LOD renderer (Fabric only)
  • Chunky — pre-generates chunks so distant terrain already exists

You can then run a pre-generation pass over a radius around spawn and watch its progress. Players still need the matching client mod to actually see the extra distance.

Can I install a whole modpack?

Yes, manually. Create a server on the pack's loader and Minecraft version, then copy the pack's server-side mods into the Mods tab. Most packs publish a dedicated server download containing exactly the right jars.

Zen Host doesn't yet read CurseForge or Modrinth .mrpack modpack files directly.

Files & worlds

Where are my server files stored?

Each server gets its own folder under the app's user-data directory:

  • Windows — %APPDATA%\zen-host\servers\
  • macOS — ~/Library/Application Support/zen-host/servers/
  • Linux — ~/.config/zen-host/servers/

The Overview tab has a button that opens the folder directly. Inside it's an ordinary Minecraft server — server jar, server.properties, world, mods — so any normal Minecraft tooling works on it.

How do I back up a world?

Stop the server first so everything is flushed to disk, then copy the world folder somewhere safe. That folder is the entire save — terrain, inventories, player data.

Copying it while the server is running risks catching a half-written region file.

Can I bring in an existing single-player world?

Yes. Create a server on the same Minecraft version, stop it, open the server folder, and replace the world folder with your save (the folder from .minecraft/saves/). Make sure the new folder is named to match the World Name setting, which is world by default.

Single-player saves keep the Nether and End inside the same folder, so they come across with it.

How do I start a fresh world?

Stop the server, open its folder, and delete (or rename) the world folder. A brand-new one is generated on the next start.

To generate a specific world, set World Seed under Settings → World before starting. Changing the seed does nothing to terrain that already exists.

Does deleting a server delete the world?

Yes — deleting a server removes its entire folder, world included, and it isn't recoverable from inside the app. Copy anything you want to keep out first.

Can I edit server.properties by hand?

You can, while the server is stopped. Zen Host reads the file fresh each time, so hand-made changes are picked up and shown in the Settings tab.

Keys the visual editor doesn't recognise are preserved and shown as plain text fields, so nothing gets dropped. Note that saving from the app rewrites the file with keys sorted alphabetically and strips comments.
